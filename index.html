Demo Project This very page

You're looking at a Zero Trust Network Access demo.

This site is hosted on GitHub Pages and published behind a Cloudflare Access policy. Nobody gets here without first proving their identity — you entered your email and received a one-time code (or your session was reused). That's clientless ZTNA: identity-based access control enforced at the edge, no VPN, no client software.

Policy: Email OTP · Session: 24h · Enforced by: Cloudflare Access

  1. You request ztna.blueberryservices.co.za
  2. Cloudflare Access checks for a valid session cookie
  3. No session → redirect to the Access login, email + one-time code
  4. Identity verified → page served from GitHub Pages origin
  5. Unauthenticated requests never reach the origin — ever
